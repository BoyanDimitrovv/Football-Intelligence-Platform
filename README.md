# Football Intelligence Platform

Интелигентна уеб платформа за футболен скаутинг, която използва машинно
обучение, база данни и AI асистент, за да препоръчва футболисти според
нуждите на даден отбор.

## Текущ етап

Проектът е в начален етап: налична е базовата структура на проекта и
минимално Flask приложение с проверка на здравето (health check).

## Изисквания

- Python 3.10+
- pip

## Инсталация

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Стартиране

```bash
python app.py
```

Приложението ще бъде достъпно на адрес `http://127.0.0.1:5000`.

## Структура на проекта

```
proekt/
├── app.py                 # Flask приложение и маршрути
├── requirements.txt       # Python зависимости
├── README.md
├── data/                  # Футболни данни (източници, импорт, сурови данни)
├── database/              # Работа с базата данни (SQLite)
├── ml/                    # Машинно обучение и препоръки
├── templates/             # HTML шаблони (Jinja2)
├── static/
│   ├── css/               # CSS стилове
│   └── js/                # JavaScript
└── tests/                 # Тестове
```

## Планирани функционалности (следващи етапи)

- търсене и филтриране на футболисти;
- сравнение на играчи;
- ML препоръки;
- статистически графики;
- AI чат асистент;
- обяснение защо даден играч е препоръчан.

## Сигурност

Не се записват тайни ключове или пароли в кода. Конфигурациите,
свързани със сигурността, се четат от променливите на средата.
